# Reference files

`references.bib` and `references.csv` contain 34 verified supporting entries for
methods, software and context. Their keys are stable identifiers, not the final
manuscript reference numbers. Only entries with verified bibliographic metadata are included.

`data_source_references.bib` contains the 44 original articles associated with
the main148 and restored three reference curves. `data_sources.csv` is the single curve-to-article mapping,
with corrected DOI metadata and an explicit attribution method. Six old
in-press source attributions use matching author/system scope rather than a new
independent extraction of the published numerical tables. That qualification is
retained in the mapping. The two bibliographies overlap and their counts must
not be summed as a unique-article count. Reuse measurements with original-article
citations and observe the separate data and weight notices.
